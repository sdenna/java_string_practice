Loop and String reference
A loop needs a starting state, a condition, and an update that moves toward stopping. Keep your accumulator outside the loop when it must survive across passes.
for (int i = START; CONDITION; UPDATE) {
    // One pass of the algorithm
}

int i = START;
while (CONDITION) {
    // One pass of the algorithm
    // UPDATE must move toward stopping
}

About this practice runner and your progress
This page runs a limited Java subset locally in your browser, rather than a full Java compiler. It supports method bodies with int, double, boolean, char, String, for, while, if / else, return, break, continue, arithmetic, assignments, and the String methods in the reference plus equalsIgnoreCase. String reference comparisons using == or != are intentionally rejected; compare contents with equals.
Write only the supplied method’s body. Classes, imports, extra methods, arrays, Scanner, objects, recursion, and other library methods are not supported. Use your normal Java environment for full compiler checks. Passing the checks confirms the listed cases; it is not a proof for every input.
Each run has execution and output limits. A loop that runs too long stops with an explanation. The trace shows the first 180 recorded events per test case. No code or results are sent to a server. Drafts and checks are saved on this browser when local storage is available; this is not a teacher gradebook. Download a summary when you want to keep or share your work.
